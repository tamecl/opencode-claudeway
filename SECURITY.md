# Seguridad

Claudeway maneja tokens OAuth. Si encuentras una vulnerabilidad, **no abras un issue público**: repórtala en privado desde la pestaña
[Security → Report a vulnerability](https://github.com/tamecl/opencode-claudeway/security/advisories/new).

Incluye la versión afectada y los pasos para reproducirla, sin tokens ni credenciales reales.

El proyecto es experimental; solo se corrige la rama `main`.

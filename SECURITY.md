# Security

Claudeway handles OAuth tokens. If you find a vulnerability, **do not open a public issue**: report it privately from
[Security → Report a vulnerability](https://github.com/tamecl/opencode-claudeway/security/advisories/new).

Include the affected version and steps to reproduce, without real tokens or credentials.

The project is experimental; only the latest published version and the `main` branch receive fixes.

Published versions are built and released from GitHub Actions with npm provenance, so you can check that a version
came from this repository: `npm audit signatures`.
